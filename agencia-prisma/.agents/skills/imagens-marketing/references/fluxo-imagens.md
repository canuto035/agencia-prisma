# Arquivos e conferência de imagens

Dentro de clientes/<cliente>/imagens/, sugira:

- originais/: fotos do cliente; nunca sobrescrever.
- referencias/: imagens que orientam estilo, luz, cor e composição.
- pesquisadas/: arquivos obtidos com condições de uso verificadas.
- tratadas/: versões editadas das fotos.
- geradas/: imagens novas produzidas por IA.
- registro-imagens.md: relação entre entrada, finalidade e resultado.

Crie somente as pastas necessárias ao trabalho. Se o usuário indicar outra pasta, utilize-a; não mova seus originais sem pedido. As imagens de clientes diferentes permanecem separadas.

No registro, inclua: identificador, arquivo de origem ou URL, papel, referência usada, ajustes solicitados, ferramenta utilizada, arquivo final, dimensões efetivas, resultado da inspeção e pendências. Para terceiros, acrescente página de licença e crédito necessário. Para uma nova versão, use nome como produto-tratada-v02.png e preserve a anterior. Não altere uma extensão para simular conversão.

No repasse para design, identifique **original → tratado/gerado selecionado → peça que o utiliza → exportação final**. Informe versão, direito de uso, dimensões reais, recorte permitido, área protegida (rosto, embalagem, texto, logo), espaço negativo e qualquer alteração de cor proibida. Em peça pontual, anote isso no briefing existente; não crie um registro extra só para cumprir a convenção.

Antes de entregar, abra a imagem final e confira a relação com o original. Se o resultado for destinado a carrossel, deixe espaço para o texto previsto e confira a consistência entre as imagens selecionadas. Para uma série, mantenha a intenção visual comum e adapte a correção à exposição de cada foto. Depois da montagem, confira a exportação da peça para detectar novo recorte, compressão, mudança de cor ou perda de detalhes no ativo aplicado; devolva ao design a correção necessária.
